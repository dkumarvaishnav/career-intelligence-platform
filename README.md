# Career Intelligence Platform

## Overview
AI-Driven Resume Intelligence and Career Guidance Platform.
Helps early-career professionals calibrate their readiness for target roles.

## Tech Stack
- **Frontend**: Next.js (React)
- **Backend**: FastAPI (Python)
- **AI**: OpenAI / LangChain

## Setup

### Backend
```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
